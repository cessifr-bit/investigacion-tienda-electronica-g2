## Configuración experimental

Las pruebas se realizarán en el mismo equipo y bajo las mismas condiciones de ejecución. Se utilizará la misma consulta de inventario para evaluar los volúmenes de 100, 500 y 1,000 registros.

Se documentarán las configuraciones relevantes de la base de datos, las herramientas de medición y el procedimiento utilizado para controlar la caché.

## Procedimiento de medición

Se registrarán el tiempo de respuesta, expresado en milisegundos (ms), y el consumo de memoria, expresado en megabytes (MB). El procedimiento de medición y las herramientas utilizadas se especificarán cuando se encuentren implementados y verificados.
