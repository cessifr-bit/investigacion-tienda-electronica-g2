# Viabilidad Técnica

## Herramientas e Infraestructura Requeridas

Para solventar la problemática el rendimiento es muy importante para las consulta y gestión de productos, en grupo se llego a la siguiente conclusión 

+Microsoft SQL Server siendo uno de los pilares ya que permite evaluar el comportamiento y saber con las consultas, la gestión siendo a su vez tomando en posible cuenta MySQL Community Server porque representa el estándar de código abierto más utilizado en entornos web.

+Se necesitara de un posible entornos de administración de las bases de datos y el mas usado es SQL Server Management Studio porque ofrece un control exhaustivo e integrado para SQL Server porque permite analizar planes de ejecución gráficos, examinar estadísticas en tiempo real para las consultas.

+IntelliJ IDEA sera el entorno de desarrollo integrado para proyectos basados en Java y la plataforma JVM. En un banco de pruebas de base de datos, su inclusión se justifica por su conectividad ya que permite construir y ejecutar de forma nativa componentes de acceso a datos para validar cómo la aplicación gestiona la capa de persistencia permite inspeccionar esquemas, ejecutar scripts SQL, analizar planes de consulta y comparar resultados de SQL Server y MySQL directamente desde el propio IDE relacionado con la herramienta anterior mencionada este facilita el medir tiempos de respuesta a nivel de código antes de lanzar pruebas de carga masivas con JMeter.
